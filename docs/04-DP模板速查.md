# DP 模板速查

## 1. 01 背包

物品 i 有重量 `w[i]`、价值 `v[i]`，背包容量 `V`，每件最多选一次。

```java
int[] dp = new int[V + 1];              // dp[j] = 容量 j 时的最大价值
for (int i = 0; i < n; i++) {
    for (int j = V; j >= w[i]; j--) {    // 必须倒序，保证每件只用一次
        dp[j] = Math.max(dp[j], dp[j - w[i]] + v[i]);
    }
}
```

## 2. 完全背包

每件物品可以选无限次 —— 内层**正序**即可。

```java
for (int i = 0; i < n; i++) {
    for (int j = w[i]; j <= V; j++) {
        dp[j] = Math.max(dp[j], dp[j - w[i]] + v[i]);
    }
}
```

## 3. 多重背包（二进制拆分）

第 i 件物品有 `c[i]` 个，拆成 1、2、4、8… 份后转成 01 背包。

```java
List<int[]> items = new ArrayList<>();   // 存 {重量, 价值}
for (int i = 0; i < n; i++) {
    int cnt = c[i], k = 1;
    while (cnt > 0) {
        int take = Math.min(k, cnt);
        items.add(new int[]{w[i] * take, v[i] * take});
        cnt -= take;
        k <<= 1;
    }
}
for (int[] it : items) {
    for (int j = V; j >= it[0]; j--) {
        dp[j] = Math.max(dp[j], dp[j - it[0]] + it[1]);
    }
}
```

## 4. 最大子段和

```java
int cur = a[0], best = a[0];
for (int i = 1; i < n; i++) {
    cur = Math.max(a[i], cur + a[i]);
    best = Math.max(best, cur);
}
```

## 5. LIS（最长上升子序列，O(n log n)）

```java
int[] tails = new int[n];
int len = 0;
for (int x : a) {
    int l = 0, r = len;
    while (l < r) {                      // 找第一个 >= x 的位置
        int mid = (l + r) >>> 1;
        if (tails[mid] < x) l = mid + 1;
        else r = mid;
    }
    tails[l] = x;
    if (l == len) len++;                 // 严格上升
}
// len 即 LIS 长度
```

要最长**不下降**子序列，把 `tails[mid] < x` 改成 `tails[mid] <= x`。

## 6. LCS（最长公共子序列）

```java
int[][] dp = new int[n + 1][m + 1];
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= m; j++) {
        if (a.charAt(i - 1) == b.charAt(j - 1)) {
            dp[i][j] = dp[i - 1][j - 1] + 1;
        } else {
            dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
        }
    }
}
// 答案 dp[n][m]
```

空间可滚到一维，但需要额外变量保存 `dp[i-1][j-1]`。

## 7. 区间 DP（石子合并 / 矩阵链乘）

```java
int[] sum = new int[n + 1];              // 前缀和，1-indexed
for (int i = 1; i <= n; i++) sum[i] = sum[i - 1] + a[i];

int[][] dp = new int[n + 1][n + 1];
for (int len = 2; len <= n; len++) {                 // 枚举区间长度
    for (int i = 1; i + len - 1 <= n; i++) {         // 枚举左端点
        int j = i + len - 1;
        dp[i][j] = Integer.MAX_VALUE;
        for (int k = i; k < j; k++) {                // 枚举分割点
            dp[i][j] = Math.min(dp[i][j],
                    dp[i][k] + dp[k + 1][j] + sum[j] - sum[i - 1]);
        }
    }
}
// 答案 dp[1][n]
```

## 8. 状压 DP

状态用二进制位表示「选了哪些」。适用于 n ≤ 20。

```java
// 例：n 个物品选若干，求某种最优值
int full = 1 << n;
int[] dp = new int[full];
for (int mask = 1; mask < full; mask++) {
    // 枚举 mask 中的每一位
    for (int i = 0; i < n; i++) {
        if ((mask >> i & 1) == 1) {
            int pre = mask ^ (1 << i);

}
```

## 9. 树形 DP（最大权独立集）

选一个点就不能选它的子节点。

```java
// dp[u][0] 不选 u，dp[u][1] 选 u
void dfs(int u, int parent, List<List<Integer>> g, int[] val, int[][] dp) {
    dp[u][1] = val[u];
    for (int v : g.get(u)) {
        if (v == parent) continue;
        dfs(v, u, g, val, dp);
        dp[u][0] += Math.max(dp[v][0], dp[v][1]);
        dp[u][1] += dp[v][0];
    }
}
```

## 10. 记忆化搜索

```java
int[][] memo = new int[n][m];
for (int[] row : memo) Arrays.fill(row, -1);

int dfs(int i, int j) {
    if (i < 0 || j < 0) return 0;            // 边界
    if (memo[i][j] != -1) return memo[i][j]; // 已算过
    int res = Math.max(dfs(i - 1, j), dfs(i, j - 1)) + a[i][j];
    return memo[i][j] = res;
}
```

## 11. 编辑距离

```java
int[][] dp = new int[n + 1][m + 1];
for (int i = 0; i <= n; i++) dp[i][0] = i;
for (int j = 0; j <= m; j++) dp[0][j] = j;
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= m; j++) {
        if (a.charAt(i - 1) == b.charAt(j - 1)) {
            dp[i][j] = dp[i - 1][j - 1];
        } else {
            dp[i][j] = 1 + Math.min(dp[i - 1][j - 1],
                    Math.min(dp[i - 1][j], dp[i][j - 1]));
        }
    }
}
```

## 12. 做题时的 DP 五步法

1. **定义状态**：`dp[i][j]` 表示什么？一句话说清楚。
2. **找转移**：最后一步从哪里来？
3. **定初值**：边界 / 空集。
4. **定顺序**：保证依赖的状态先算出来。
5. **找答案**：是 `dp[n]` 还是 `max(dp[...])`？

> 想不出转移时，先写暴力递归，再看能不能加记忆化。
