# 备赛路线（Java 大学 B 组）

## 一、先搞清楚赛制

- 省赛（4 月）：约 8~10 题，含填空题与编程题，时长 4 小时，OI 赛制（按测试点给分，可反复提交）。
- 国赛（6 月）：难度更高，图论 / DP / 数据结构占比上升。
- 具体题量、分值与时长以官网通知和准考证为准。

关键认知：**OI 赛制下，暴力也是分**。一道题 10 个测试点，暴力能过 4 个就是 40 分，比空着强得多。

## 二、四个阶段

### 阶段 1：基础扫盲（2~3 周）

目标：任何简单题都能在 20 分钟内 AC。

- Java 语法：数组、`ArrayList`、`HashMap`、`TreeMap`、`PriorityQueue`、`StringBuilder`
- 排序：`Arrays.sort`、对象排序、`Comparator` 写法
- 枚举、模拟、日期处理、进制转换
- 大数：`BigInteger`、`BigDecimal`
- 输入输出：`Scanner` 够用，数据量大时换 `FastIO`

### 阶段 2：专题突破（4~6 周）

按顺序刷，每个专题 8~15 题：

1. 前缀和 / 差分 / 双指针
2. 二分（手写 lower/upper bound、二分答案）
3. 贪心
4. 搜索（DFS / BFS / 回溯 / 剪枝）
5. DP（背包 → 线性 → 区间 → 状压 → 树形）
6. 图论（存图、遍历、拓扑、最短路、最小生成树、并查集）
7. 数论（质数筛、约数、快速幂、逆元、组合数）
8. 字符串（KMP、哈希）
9. 数据结构（树状数组、线段树、单调栈 / 单调队列）

### 阶段 3：真题实战（3~4 周）

- 按年份从旧到新，限时 4 小时整套做省赛 Java B 组
- 做完必须写题解：思路、复杂度、踩的坑
- 整理错题本，标注「不会的知识点」→ 回到阶段 2 补

### 阶段 4：冲刺（1~2 周）

- 每天默写 1~2 个模板，做到不看源码能写对
- 重做错题，只看题目能独立写出
- 熟悉考场策略（见 [03-考场策略与检查清单.md](03-考场策略与检查清单.md)）

## 三、每周安排建议

| 时间 | 内容 |
|---|---|
| 周一~周五 每晚 2h | 1 个专题的 2~3 道题 |
| 周六 4h | 整套真题限时训练 |
| 周日 2h | 复盘 + 写题解 + 默写模板 |

## 四、推荐刷题顺序

1. 蓝桥云课「蓝桥杯历年真题」→ 省赛 B 组
2. Dotcpp 蓝桥杯真题（有 OJ 评测）
3. 洛谷「入门 / 普及-」补基础
4. AcWing 算法基础课（专题体系完整）
5. Codeforces Div.3 / Div.4（练手速和思维）

## 五、避坑提醒

- 不要只刷题不总结：同类题刷 3 道就归纳模板
- 不要死磕难题：OI 赛制下先把能拿的分拿满
- 不要依赖 IDE 补全：考场环境可能只有简单编辑器，模板要能默写
- 不要忽视填空题：填空题往往用暴力/数学就能拿分，性价比极高
