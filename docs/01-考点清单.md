# 考点清单

按模块拆解，频率是省赛 B 组的经验判断，掌握度自己填（1~5 分）。

## 一、基础（必拿分）

| 考点 | 频率 | 掌握度 | 关键点 |
|---|---|---|---|
| 枚举 / 模拟 | 极高 | | 读懂题意，按步骤翻译成代码 |
| 排序 | 极高 | | `Arrays.sort` 对基本类型是快排，对象是归并（稳定） |
| 日期时间 | 高 | | `LocalDate` 或手写闰年判断；注意 0 点、月末 |
| 进制转换 | 高 | | `Integer.toString(x, radix)`、`BigInteger` |
| 大数运算 | 高 | | `BigInteger` 加减乘除、`mod`、`gcd` |
| 字符串处理 | 高 | | `StringBuilder`、`split`、`charAt` |
| 前缀和 / 差分 | 高 | | 区间求和、区间加 |
| 双指针 / 滑动窗口 | 中 | | 连续子数组问题 |

## 二、搜索

| 考点 | 频率 | 掌握度 | 关键点 |
|---|---|---|---|
| DFS / 回溯 | 极高 | | 全排列、子集、棋盘类；记得恢复现场 |
| BFS | 极高 | | 最短步数、连通块；用 `ArrayDeque`，不要用 `Stack` |
| 剪枝 | 高 | | 可行性剪枝 + 最优性剪枝 |
| 记忆化搜索 | 中 | | 递归 + 缓存，本质是 DP |
| 双向 BFS / 迭代加深 | 低 | | 状态空间大但解浅 |

## 三、动态规划

| 考点 | 频率 | 掌握度 | 关键点 |
|---|---|---|---|
| 01 背包 / 完全背包 / 多重背包 | 极高 | | 一维滚动时**容量要倒序**（01 背包） |
| 线性 DP | 极高 | | 最大子段和、数字三角形、打家劫舍 |
| LIS / LCS | 高 | | LIS 有 O(n log n) 贪心 + 二分写法 |
| 区间 DP | 中 | | 石子合并、括号匹配；先枚举区间长度 |
| 状压 DP | 低 | | 状态用二进制表示，n 一般 ≤ 20 |
| 树形 DP | 低 | | 后序遍历 + 选 / 不选 |

详见 [04-DP模板速查.md](04-DP模板速查.md)。

## 四、图论

| 考点 | 频率 | 掌握度 | 关键点 |
|---|---|---|---|
| 存图（邻接表） | 极高 | | `List<List<int[]>>`，边存 `{to, weight}` |
| 遍历 / 连通块 | 极高 | | DFS 或 BFS |
| 拓扑排序 | 中 | | 入度为 0 入队；判环：结果数 < n |
| 并查集 | 高 | | 路径压缩 + 按大小合并 |
| Dijkstra | 高 | | 边权非负，`PriorityQueue` 优化 |
| Floyd | 中 | | 多源最短路，n ≤ 500 |
| Kruskal | 中 | | 边排序 + 并查集 |
| SPFA / Bellman-Ford | 低 | | 有负权边时用 |
| 二分图判定 | 低 | | 染色法 |

## 五、数学

| 考点 | 频率 | 掌握度 | 关键点 |
|---|---|---|---|
| 素数判定 / 素数筛 | 高 | | 试除到 √n；埃氏筛 O(n log log n) |
| 最大公约数 / 最小公倍数 | 高 | | `lcm = a / gcd * b`，先除后乘防溢出 |
| 快速幂 | 高 | | 矩阵快速幂可求递推 |
| 扩展欧几里得 | 中 | | 解 ax + by = gcd |
| 逆元 | 中 | | 模数为质数时用费马小定理 |
| 组合数 | 中 | | 预处理阶乘 + 逆元阶乘 |
| 唯一分解定理 | 中 | | 约数个数、约数和 |
| 容斥原理 | 低 | | 求并集大小 |

## 六、数据结构

| 考点 | 频率 | 掌握度 | 关键点 |
|---|---|---|---|
| 栈 / 队列 / 优先队列 | 极高 | | `ArrayDeque` 当栈和队列都比老的快 |
| 哈希表 | 极高 | | `HashMap` 计数、去重 |
| 树状数组 | 中 | | 单点改 + 前缀和；也可做区间加 |
| 线段树 | 中 | | 带 lazy 的区间改 + 区间查 |
| 单调栈 / 单调队列 | 中 | | 下一个更大元素、滑动窗口最值 |
| Trie | 低 | | 前缀匹配、异或最大值 |

## 七、自我评估

每个月回填一次掌握度，**低于 3 分的必须优先补**。

- 1 分：完全不会
- 2 分：看得懂题解，写不出来
- 3 分：能照着模板写出来
- 4 分：不看模板能写对
- 5 分：能变形、能优化、能讲清楚
