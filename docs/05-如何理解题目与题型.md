# 如何理解题目与题型

> 大部分「不会做」不是算法不会，而是没读懂题、没判断出该用什么复杂度。

## 一、读题三遍法

| 遍数 | 目标 | 动作 |
|---|---|---|
| 第 1 遍 | 知道在讲什么 | 只看故事，不看数据范围，用自己的话概括 |
| 第 2 遍 | 提取约束 | 圈出输入、输出、数据范围、特殊限制 |
| 第 3 遍 | 反推算法 | 用数据范围推出可接受的复杂度，再匹配题型 |

## 二、把题面拆成五件事

拿到题先填这张表，填不出来就是没读懂：

| 项目 | 要回答的问题 |
|---|---|
| 输入 | 给什么？几个数？什么结构（数组/图/字符串）？ |
| 输出 | 求什么？一个数、一个方案，还是所有方案？ |
| 范围 | n、m、值域、时间限制是多少？ |
| 限制 | 有没有「不重复」「连续」「有序」「非负」等关键词？ |
| 样例 | 手算一遍样例，确认理解没偏 |

## 三、数据范围 → 可接受复杂度

这是最重要的一步。看到 n 就能排除掉一大半算法。

| n 的范围 | 可接受复杂度 | 典型算法 |
|---|---|---|
| n ≤ 10 | O(n!) / O(2^n · n) | 全排列、状压 DP |
| n ≤ 20 | O(2^n) | 子集枚举、状压 DP |
| n ≤ 100 | O(n^3) | Floyd、区间 DP |
| n ≤ 500 | O(n^2) | 二维 DP、暴力枚举 |
| n ≤ 5000 | O(n^2) 勉强 | 需常数小 |
| n ≤ 10^5 | O(n log n) | 排序、二分、树状数组 |
| n ≤ 10^6 | O(n) / O(n log n) | 前缀和、筛法、双指针 |
| n ≤ 10^9 | O(log n) / O(1) | 快速幂、数学公式、二分答案 |
| n ≤ 10^18 | O(log n) | 矩阵快速幂、数位 DP、公式 |

经验：**1 秒大约能跑 10^7 ~ 10^8 次基本操作**，Java 保守按 10^7 估。

## 四、题型识别表

| 题面特征 | 优先考虑 |
|---|---|
| 规则明确、范围小、让你「按步骤执行」 | 枚举 / 模拟 |
| 求最大/最小、有「选择」、能交换论证 | 贪心 |
| 多次询问区间和 / 区间加 | 前缀和 / 差分 |
| 有序数组查找、求「最小的最大值」 | 二分 / 二分答案 |
| 连续子数组、和/长度满足某条件 | 双指针 / 滑动窗口 |
| 网格、棋盘、连通、最短步数、所有方案 | BFS / DFS / 回溯 |
| 求方案数、最优值、有重叠子问题 | 动态规划 |
| 点与边、路径、连通块、依赖关系 | 图论 |
| 质数、约数、取模、大指数、方案数 | 数论 |
| 子串匹配、回文、重复出现 | 字符串 |
| 动态求第 k 大、下一个更大、区间最值 | 数据结构 |

## 五、五步解题法

1. **理解**：填完上面的表，手算样例。
2. **建模**：把题目抽象成「数组 / 图 / 状态」。
3. **暴力**：先写出一定能过的暴力解，明确复杂度。
4. **优化**：对照数据范围，找瓶颈（重复计算 / 枚举太多）。
5. **验证**：样例 + 边界（n=1、全相同、全不同、最大范围）。

> 考场上第 3 步就要提交一次，先拿部分分，再做第 4 步。

## 六、常见题面陷阱

- 「连续」和「不连续」是两种题，别混。
- 「子序列」不要求连续，「子数组/子串」要求连续。
- 「输出方案」和「输出方案数」完全不同。
- 多组数据：每组都要重新初始化数组和变量。
- 下标从 0 还是 1：题目说「第 1 个」时，建议统一用 1-indexed。
- 取模：结果可能为负时要 `(x % MOD + MOD) % MOD`。
- 「至少 / 至多 / 恰好」：边界条件不同。

## 七、完整示例：区间求和

**题目**：给长度为 n 的数组，q 次询问，每次求 [l, r] 的和。n, q ≤ 10^5。

1. 拆题：输入数组 + q 个区间；输出 q 个和；范围 10^5。
2. 规模判断：O(nq) = 10^10，必超时；需要 O(n + q) 或 O((n+q) log n)。
3. 暴力：每次循环累加，O(nq)，只能过小数据。
4. 优化：前缀和预处理 O(n)，每次询问 O(1)。
5. 验证：l=1 时 `pre[r] - pre[0]`，r=n 时不越界。

```java
long[] pre = new long[n + 1];
for (int i = 1; i <= n; i++) {
    pre[i] = pre[i - 1] + a[i - 1];
}
long ans = pre[r] - pre[l - 1];
```

同样的思考流程适用于所有题型：**先看范围定复杂度，再找重复计算，最后套模板**。
