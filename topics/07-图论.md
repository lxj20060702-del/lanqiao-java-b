# 题型 07 · 图论

> 一句话：**把「点与点的关系」建成图，再用遍历、最短路、并查集回答连通与路径问题。**

## 1. 概念：这个题型在考什么

- 图的两种存储：邻接矩阵（n ≤ 500，适合 Floyd）、邻接表（稀疏图，最常用）。
- 遍历：DFS / BFS，解决连通块、可达性。
- 最短路：Dijkstra（非负边权）、Floyd（多源、n 小）。
- 最小生成树：Kruskal（排序 + 并查集）。
- 并查集：只关心「是否连通」，不关心路径。
- 省赛地位：省赛常考连通块和简单最短路；国赛考组合图论。

## 2. 如何识别

| 题面特征 | 判断 |
|---|---|
| 城市 / 站点 / 人之间有连接关系 | 建图 |
| 求两点最短距离 | Dijkstra / Floyd |
| 求有几个连通块 / 是否连通 | DFS 或并查集 |
| 修路使全部连通、代价最小 | 最小生成树 |
| 任务有先后依赖、判断能否完成 | 拓扑排序 |
| 边权有负数 | Bellman-Ford（Dijkstra 失效） |

范围信号：n ≤ 500 且多源 → Floyd O(n³)；n、m ≤ 10^5 → 邻接表 + Dijkstra O(m log n)。

## 3. 从低分到满分

**例题**：单源最短路，n 个点 m 条边，求 1 号点到所有点的最短距离。

### 3.1 暴力：Floyd（小图能过）

```java
for (int k = 0; k < n; k++)
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            d[i][j] = Math.min(d[i][j], d[i][k] + d[k][j]);
```

- O(n³)，n = 500 时约 1.25×10^8，勉强；n = 10^5 完全不可行。
- 好处：能处理负权（无负环），代码极短。

### 3.2 满分：Dijkstra + 优先队列

```java
static long[] dijkstra(List<List<int[]>> g, int start) {
    int n = g.size();
    long inf = Long.MAX_VALUE / 4;
    long[] dist = new long[n];
    Arrays.fill(dist, inf);
    dist[start] = 0;
    PriorityQueue<long[]> pq = new PriorityQueue<>((a, b) -> Long.compare(a[1], b[1]));
    pq.offer(new long[]{start, 0});
    while (!pq.isEmpty()) {
        long[] cur = pq.poll();
        int u = (int) cur[0];
        if (cur[1] > dist[u]) continue;       // 过期状态
        for (int[] e : g.get(u)) {
            int v = e[0];
            long nd = dist[u] + e[1];
            if (nd < dist[v]) {
                dist[v] = nd;
                pq.offer(new long[]{v, nd});
            }
        }
    }
    return dist;
}
```

- O(m log n)，适合 n、m ≤ 10^5。
- 前提：**边权非负**。

| 解法 | 复杂度 | 适用 |
|---|---|---|
| Floyd | O(n³) | n ≤ 500，多源，可有负权 |
| Dijkstra | O(m log n) | 单源，边权非负 |

## 4. 并查集模板

```java
static int[] parent;
static int find(int x) {
    return parent[x] == x ? x : (parent[x] = find(parent[x]));
}
static void union(int a, int b) {
    parent[find(a)] = find(b);
}
```

## 5. 小试牛刀

### 练习 1 · 单源最短路（中）

n 个点 m 条有向边，边权为正。求 1 号点到每个点的最短距离，不可达输出 -1。

**输入**：第一行 `n m`；接下来 m 行 `u v w`

**输出**：一行 n 个整数

**样例**

```text
输入：
5 6
1 2 2
1 3 4
2 3 1
2 4 7
3 5 3
4 5 1
输出：0 2 3 9 6
```

<details>
<summary>参考答案</summary>

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt(), m = sc.nextInt();
        List<List<int[]>> g = new ArrayList<>();
        for (int i = 0; i <= n; i++) g.add(new ArrayList<>());
        for (int i = 0; i < m; i++) {
            int u = sc.nextInt(), v = sc.nextInt(), w = sc.nextInt();
            g.get(u).add(new int[]{v, w});     // 有向图只存一次
        }

        long inf = Long.MAX_VALUE / 4;
        long[] dist = new long[n + 1];
        Arrays.fill(dist, inf);
        dist[1] = 0;
        PriorityQueue<long[]> pq = new PriorityQueue<>((a, b) -> Long.compare(a[1], b[1]));
        pq.offer(new long[]{1, 0});
        while (!pq.isEmpty()) {
            long[] cur = pq.poll();
            int u = (int) cur[0];
            if (cur[1] > dist[u]) continue;
            for (int[] e : g.get(u)) {
                long nd = dist[u] + e[1];
                if (nd < dist[e[0]]) {
                    dist[e[0]] = nd;
                    pq.offer(new long[]{e[0], nd});
                }
            }
        }

        StringBuilder sb = new StringBuilder();
        for (int i = 1; i <= n; i++) {
            if (i > 1) sb.append(' ');
            sb.append(dist[i] >= inf ? -1 : dist[i]);
        }
        System.out.println(sb);
    }
}
```

</details>

**满分要点**：1-indexed 建图；有向图只存一次；long + 大 INF；过期状态 `cur[1] > dist[u]` 跳过。
**常见失分**：无向图只存一次；INF 用 `Integer.MAX_VALUE` 导致加法溢出；忘记处理不可达。

### 练习 2 · 连通块（易）

n 个点 m 条无向边，求连通块数量。

**输入**：第一行 `n m`；接下来 m 行 `u v`

**输出**：连通块数量

**样例**

```text
输入：
5 4
1 2
2 3
4 5
1 3
输出：2
```

<details>
<summary>参考答案</summary>

```java
import java.util.*;

public class Main {
    static int[] parent;

    static int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt(), m = sc.nextInt();
        parent = new int[n + 1];
        for (int i = 1; i <= n; i++) parent[i] = i;
        int components = n;
        for (int i = 0; i < m; i++) {
            int a = find(sc.nextInt()), b = find(sc.nextInt());
            if (a != b) {
                parent[a] = b;
                components--;
            }
        }
        System.out.println(components);
    }
}
```

时间近似 O(n + m α(n))。

</details>

**满分要点**：路径压缩；每成功合并一次计数减一；1-indexed 初始化。
**常见失分**：初始化为 0；重复边也减计数；忘记路径压缩导致 TLE。

## 6. AI 评分要点

- 有向图还是无向图，边是否存了两次。
- Dijkstra 的 INF 是否足够大（推荐 `Long.MAX_VALUE / 4`）。
- 是否处理了重边、自环、不可达。
- 节点编号 0-indexed 还是 1-indexed，数组是否开够。
- 边权有负数时是否误用 Dijkstra。
