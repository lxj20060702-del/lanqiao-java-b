# 题型 01 · 枚举与模拟

> 一句话：**把所有可能逐个试一遍（枚举），或按题目描述的规则一步步执行（模拟）。**

## 1. 概念：这个题型在考什么

- **枚举**：确定一个候选集合，用循环把每个候选都检查一遍，取最优或计数。
- **模拟**：题目已经给定了完整规则，你只需要忠实地把规则翻译成代码，不需要想算法。
- 为什么有效：当候选数量在可接受范围内，枚举是**最简单且不容易错**的正确答案。
- 省赛地位：填空题和简单编程题的主力，也是所有题「先拿部分分」的兜底方案。

关键不是「会不会写 for」，而是想清楚两件事：**枚举什么**、**怎么判断一个候选是否合法**。

## 2. 如何识别

| 题面特征 | 判断 |
|---|---|
| 规则写得很清楚，让你「按顺序执行」 | 模拟 |
| 数据范围很小（n ≤ 1000，或答案空间有限） | 枚举 |
| 求「有多少个满足条件的数 / 方案」 | 枚举 + 判断 |
| 日期、进制、棋盘、排队、计费 | 模拟 |
| 没有明显的「最优子结构」 | 先想枚举 |

范围信号：

- n ≤ 10^3，双重循环 O(n²) 可以直接写。
- n ≤ 10^6，只能单层循环 O(n)。
- n ≤ 10^9，**不能枚举每个数**，要找公式或按位枚举。

## 3. 从低分到满分

**例题**：求 1 ~ n 中所有能被 3 或 5 整除的数的和，n ≤ 10^9。

### 3.1 暴力枚举（小数据能过）

```java
long sum = 0;
for (int i = 1; i <= n; i++) {
    if (i % 3 == 0 || i % 5 == 0) {
        sum += i;
    }
}
```

- 复杂度 O(n)，n = 10^9 时约 10 亿次取模，必超时。
- 预计只能过 n ≤ 10^6 的测试点。

### 3.2 满分解法：等差数列 + 容斥

1 ~ n 中 d 的倍数有 `n / d` 个，和为首项 d、末项 `d * cnt` 的等差数列。

```java
static long sumOfMultiples(long n, long d) {
    long cnt = n / d;
    return d * cnt * (cnt + 1) / 2;
}

long ans = sumOfMultiples(n, 3) + sumOfMultiples(n, 5) - sumOfMultiples(n, 15);
```

- 复杂度 O(1)，n 到 10^18 也能算。
- 注意 **15 被重复计算了一次**，要减去（容斥原理）。
- 乘法要用 long，`d * cnt * (cnt + 1)` 在 n = 10^9 时约为 3×10^17，int 必溢出。

| 解法 | 复杂度 | 得分 |
|---|---|---|
| 暴力枚举 | O(n) | 小数据 |
| 公式 + 容斥 | O(1) | 满分 |

## 4. 模拟题通用模板

```java
// 读入 → 按规则循环 → 输出
long state = 初始值;
for (int step = 1; ; step++) {
    // 1. 按题意更新 state
    // 2. 判断是否结束
    if (满足结束条件) {
        System.out.println(step);
        break;
    }
}
```

模拟题的两条铁律：**边界条件先想清楚**、**能用公式就别一天一天模拟**。

## 5. 小试牛刀

### 练习 1 · 蜗牛爬井（易）

井深 `h` 米。蜗牛白天向上爬 `a` 米，晚上下滑 `b` 米（`a > b`）。问第几天能爬出井口（白天到达或超过井口即算爬出）。

**输入**：一行三个整数 `h a b`（1 ≤ h ≤ 10^9，1 ≤ b < a ≤ 10^4）

**输出**：一个整数，表示天数

**样例**

```text
输入：10 3 2
输出：8
```

提示：最后一天爬出去之后不会再下滑，所以先算「最后一天之前需要净爬多少」。

<details>
<summary>参考答案</summary>

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        long h = sc.nextLong(), a = sc.nextLong(), b = sc.nextLong();
        long ans;
        if (h <= a) {
            ans = 1;
        } else {
            long need = h - a;                 // 最后一天之前要累计的净高度
            long perDay = a - b;
            ans = 1 + (need + perDay - 1) / perDay;
        }
        System.out.println(ans);
    }
}
```

复杂度 O(1)。逐天模拟是 O(h)，h = 10^9 会超时。

</details>

**满分要点**：`h <= a` 的特判；向上取整 `(need + perDay - 1) / perDay`。
**常见失分**：忘记最后一天不下滑；用 int 导致溢出；h 很大时逐天模拟 TLE。

### 练习 2 · 一年中的第几天（易）

给定年月日，求这一天是这一年的第几天。

**输入**：一行三个整数 `y m d`（1900 ≤ y ≤ 2100）

**输出**：一个整数

**样例**

```text
输入：2024 3 1
输出：61
```

提示：闰年规则 `(y % 4 == 0 && y % 100 != 0) || y % 400 == 0`，2024 年 2 月有 29 天。

<details>
<summary>参考答案</summary>

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int y = sc.nextInt(), m = sc.nextInt(), d = sc.nextInt();
        int[] days = {0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
        if ((y % 4 == 0 && y % 100 != 0) || y % 400 == 0) {
            days[2] = 29;
        }
        int ans = d;
        for (int i = 1; i < m; i++) {
            ans += days[i];
        }
        System.out.println(ans);
    }
}
```

复杂度 O(12)。

</details>

**满分要点**：闰年判断完整（能被 400 整除也算）；月份数组用 1-indexed 更直观。
**常见失分**：只判断 `y % 4 == 0`；把 1 月写成 `ans = 0` 忘记加 d。

### 练习 3 · 电梯（易）

电梯从 0 层出发，依次响应 n 个请求楼层。每上升一层用 6 秒，每下降一层用 4 秒，每次停靠（包括到达请求楼层）用 5 秒。求总耗时。

**输入**：第一行 n（1 ≤ n ≤ 10^5），第二行 n 个整数表示目标楼层

**输出**：总耗时

**样例**

```text
输入：
3
2 1 3
输出：43
```

解释：0→2 用 12 + 5 = 17，2→1 用 4 + 5 = 9，1→3 用 12 + 5 = 17，合计 43。

<details>
<summary>参考答案</summary>

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        long cur = 0, total = 0;          // total 必须用 long
        for (int i = 0; i < n; i++) {
            long target = sc.nextLong();
            if (target > cur) {
                total += (target - cur) * 6;
            } else {
                total += (cur - target) * 4;
            }
            total += 5;                   // 到达后停靠
            cur = target;
        }
        System.out.println(total);
    }
}
```

复杂度 O(n)。

</details>

**满分要点**：三要素写全（当前楼层、移动规则、停靠）；同层请求也要加 5 秒；long。
**常见失分**：上升和下降的费率写反；忘记停靠时间；用 int 导致 n 大时溢出。

### 练习 4 · 倍数补集（中）

求 1 ~ n 中**既不是 3 的倍数、也不是 5 的倍数**的所有整数之和。

**输入**：一个整数 n（1 ≤ n ≤ 10^9）

**输出**：一个整数

**样例**

```text
输入：10
输出：22
```

解释：满足条件的是 1、2、4、7、8，和为 22。

提示：n = 10^9 时 for 循环必然超时，先算总和，再减去 3 和 5 的倍数，注意 15 被减了两次。

<details>
<summary>参考答案</summary>

```java
import java.util.*;

public class Main {
    static long sumOfMultiples(long n, long d) {
        long cnt = n / d;
        return d * cnt * (cnt + 1) / 2;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        long n = sc.nextLong();
        long total = n * (n + 1) / 2;
        long ans = total
                - sumOfMultiples(n, 3)
                - sumOfMultiples(n, 5)
                + sumOfMultiples(n, 15);   // 容斥：15 的倍数被多减了一次
        System.out.println(ans);
    }
}
```

复杂度 O(1)。

</details>

**满分要点**：容斥原理（减 3、减 5、加回 15）；等差数列求和 O(1)；long。
**常见失分**：直接写 `for (i = 1; i <= n; i++)` 导致 TLE；漏掉加回 15；`n * (n + 1)` 用 int 溢出。

## 6. AI 评分要点

用 [AI 评分指南](../docs/06-AI评分指南.md) 的通用提示词，本题型额外检查：

- 循环边界是 `<= n` 还是 `< n`，有没有漏掉首尾。
- 是否存在「看起来能过，但 n = 10^9 时 TLE」的逐项模拟。
- 计数、求和是否用了 long。
- 日期题的闰年、月末、跨年是否正确。
- 模拟题的结束条件是否在所有分支都成立，会不会死循环。
