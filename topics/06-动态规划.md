# 题型 06 · 动态规划

> 一句话：**把大问题拆成重叠的小问题，记住小问题的答案，避免重复计算。**

## 1. 概念：这个题型在考什么

DP 合法的两个条件：

- **最优子结构**：大问题的最优解由小问题的最优解推出。
- **重叠子问题**：不同的路径会反复算同一个子问题。

解题五步：

1. 定义状态 `dp[...]` 的含义（一句话说清）。
2. 写转移方程（当前状态从哪些旧状态来）。
3. 确定初值和边界。
4. 确定遍历顺序（保证依赖先算）。
5. 确定答案位置。

## 2. 如何识别

| 题面特征 | 判断 |
|---|---|
| 求方案数 / 最大最小价值 | DP 候选 |
| 每个物品「选或不选」 | 背包 |
| 序列上求最长 / 最多 | 线性 DP、LIS |
| 两个字符串比较 | LCS、编辑距离 |
| 区间合并、括号匹配 | 区间 DP |
| n ≤ 20 且状态是集合 | 状压 DP |

范围信号：`n × V` 在 10^7 以内，基本就是背包；n ≤ 1000 常见 O(n²) 线性 DP。

## 3. 从低分到满分

**例题**：爬楼梯，每次走 1 或 2 阶，求走到第 n 阶的方法数。

### 3.1 暴力递归（n ≤ 30 能过）

```java
static long f(int n) {
    if (n <= 2) return n;
    return f(n - 1) + f(n - 2);
}
```

- 复杂度 O(2^n)，n = 40 就明显卡顿。
- 同一个 `f(k)` 被重复计算了指数次。

### 3.2 记忆化搜索（满分，但常数略大）

```java
static long[] memo = new long[100];
static long f(int n) {
    if (n <= 2) return n;
    if (memo[n] != 0) return memo[n];
    return memo[n] = f(n - 1) + f(n - 2);
}
```

- 复杂度 O(n)，思路和暴力几乎一样，只加了一个缓存。

### 3.3 递推 + 滚动数组（最优）

```java
long a = 1, b = 2;                 // f(1), f(2)
for (int i = 3; i <= n; i++) {
    long c = a + b;
    a = b;
    b = c;
}
System.out.println(n == 1 ? 1 : b);
```

- 时间 O(n)，空间 O(1)。

| 解法 | 时间 | 空间 | 得分 |
|---|---|---|---|
| 暴力递归 | O(2^n) | O(n) | n ≤ 30 |
| 记忆化 | O(n) | O(n) | 满分 |
| 滚动递推 | O(n) | O(1) | 满分 |

## 4. 01 背包模板

```java
int[] dp = new int[V + 1];
for (int i = 0; i < n; i++) {
    for (int j = V; j >= w[i]; j--) {       // 倒序：每件物品只用一次
        dp[j] = Math.max(dp[j], dp[j - w[i]] + v[i]);
    }
}
```

完全背包把内层改成**正序**；多重背包用二进制拆分。详见 [DP 模板速查](../docs/04-DP模板速查.md)。

## 5. 小试牛刀

### 练习 1 · 01 背包（中）

n 件物品，第 i 件重量 `w[i]`、价值 `v[i]`，背包容量 V，每件最多选一次，求最大总价值。

**输入**：第一行 `n V`；接下来 n 行每行 `w v`

**输出**：最大总价值

**样例**

```text
输入：
4 5
1 2
2 4
3 4
4 5
输出：8
```

解释：选第 2、3 件，重量 5，价值 8。

<details>
<summary>参考答案</summary>

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt(), V = sc.nextInt();
        int[] w = new int[n], v = new int[n];
        for (int i = 0; i < n; i++) {
            w[i] = sc.nextInt();
            v[i] = sc.nextInt();
        }
        long[] dp = new long[V + 1];
        for (int i = 0; i < n; i++) {
            for (int j = V; j >= w[i]; j--) {
                dp[j] = Math.max(dp[j], dp[j - w[i]] + v[i]);
            }
        }
        System.out.println(dp[V]);
    }
}
```

时间 O(nV)，空间 O(V)。

</details>

**满分要点**：内层**倒序**；`j >= w[i]`；价值用 long。
**常见失分**：内层正序（变成完全背包，物品可重复选）；二维数组忘记初始化；越界 `j - w[i] < 0`。

### 练习 2 · 最长上升子序列（中）

给长度 n 的序列，求最长严格上升子序列的长度（不要求连续）。

**输入**：第一行 n；第二行 n 个整数

**输出**：最长长度

**样例**

```text
输入：
8
10 9 2 5 3 7 101 18
输出：4
```

解释：2, 3, 7, 101（或 2, 3, 7, 18）。

<details>
<summary>参考答案</summary>

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) a[i] = sc.nextInt();

        int[] tails = new int[n];
        int len = 0;
        for (int x : a) {
            int l = 0, r = len;
            while (l < r) {                 // 找第一个 >= x 的位置
                int mid = (l + r) >>> 1;
                if (tails[mid] < x) l = mid + 1;
                else r = mid;
            }
            tails[l] = x;
            if (l == len) len++;
        }
        System.out.println(len);
    }
}
```

贪心 + 二分，时间 O(n log n)；经典 O(n²) 的 DP 是 `dp[i] = max(dp[j]) + 1`。

</details>

**满分要点**：严格上升用 `< x`；不下降改用 `<= x`；`tails` 长度最多 n。
**常见失分**：把「子序列」当成「子数组」；二分边界写错；输出 `tails` 数组长度而不是 len。

## 6. AI 评分要点

- 状态定义是否说清楚，`dp[i]` 到底表示「以 i 结尾」还是「前 i 个」。
- 遍历方向是否满足依赖（背包倒序、区间 DP 按长度）。
- 初值是否正确（求最大值时初始化为 0 还是 -INF）。
- 答案取 `dp[n]` 还是 `max(dp[...])`。
- 是否用 long；二维 DP 是否可能内存超限（需要滚动数组）。
