# 题型 08 · 数论

> 一句话：**把「试」变成「筛」，把「乘很多次」变成「快速幂」，把「除法」变成「逆元」。**

## 1. 概念：这个题型在考什么

- 质数：试除法 O(√n)，批量用埃氏筛 O(n log log n)。
- 约数与质因数：唯一分解定理 `n = p1^a1 · p2^a2 · ...`。
- 同余：快速幂、逆元、组合数取模。
- 常见结论：`gcd(a,b) * lcm(a,b) = a * b`；费马小定理求逆元。
- 省赛地位：填空题常考质数、日期、大数；编程题常考快速幂和组合数。

## 2. 如何识别

| 题面特征 | 判断 |
|---|---|
| 判断质数 / 统计质数个数 | 试除 / 筛法 |
| 求约数个数、约数和、质因数 | 唯一分解 |
| 求 a^b mod p，b 很大 | 快速幂 |
| 求方案数并取模 | 组合数 + 逆元 |
| 求最大公约数、最小公倍数 | gcd |
| 同余方程 ax ≡ b (mod m) | exgcd / 逆元 |

范围信号：n ≤ 10^7 可用筛；指数 b ≤ 10^18 必须快速幂；组合数 n ≤ 10^6 预处理阶乘。

## 3. 从低分到满分

**例题**：统计 1 ~ n 中质数的个数，n ≤ 10^7。

### 3.1 逐个试除（小数据能过）

```java
static boolean isPrime(long n) {
    if (n < 2) return false;
    for (long i = 2; i * i <= n; i++)
        if (n % i == 0) return false;
    return true;
}
// 对每个 i 调用
```

- 总复杂度 O(n√n)，n = 10^7 时约 3×10^10，必超时。

### 3.2 满分：埃氏筛

```java
static int countPrimes(int n) {
    boolean[] isPrime = new boolean[n + 1];
    Arrays.fill(isPrime, 2, n + 1, true);
    for (int i = 2; (long) i * i <= n; i++) {
        if (isPrime[i]) {
            for (int j = i * i; j <= n; j += i) {
                isPrime[j] = false;
            }
        }
    }
    int cnt = 0;
    for (int i = 2; i <= n; i++) if (isPrime[i]) cnt++;
    return cnt;
}
```

- O(n log log n)，n = 10^7 约 0.1 秒。
- `i * i` 用 long 防止溢出；内层从 `i * i` 开始。

| 解法 | 复杂度 | 得分 |
|---|---|---|
| 逐个试除 | O(n√n) | n ≤ 10^4 |
| 埃氏筛 | O(n log log n) | 满分 |

## 4. 快速幂模板

```java
static long pow(long base, long exp, long mod) {
    long res = 1 % mod;
    base %= mod;
    while (exp > 0) {
        if ((exp & 1) == 1) res = res * base % mod;
        base = base * base % mod;
        exp >>= 1;
    }
    return res;
}
```

## 5. 小试牛刀

### 练习 1 · 质因数分解（易）

给正整数 n，按从小到大输出它的所有质因数（重复的也要输出）。

**输入**：一个整数 n（2 ≤ n ≤ 10^12）

**输出**：一行，空格分隔

**样例**

```text
输入：360
输出：2 2 2 3 3 5
```

<details>
<summary>参考答案</summary>

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        long n = sc.nextLong();
        StringBuilder sb = new StringBuilder();
        for (long i = 2; i * i <= n; i++) {
            while (n % i == 0) {
                sb.append(i).append(' ');
                n /= i;
            }
        }
        if (n > 1) sb.append(n);        // 剩下的是大于 √n 的质因子
        System.out.println(sb.toString().trim());
    }
}
```

复杂度 O(√n)。

</details>

**满分要点**：循环条件 `i * i <= n` 且用 long；除完后的 `n > 1` 要输出；去掉末尾空格。
**常见失分**：`i * i` 用 int 溢出；忘记剩余质因子；n 为质数时输出为空。

### 练习 2 · 快速幂（易）

求 `a^b mod p`。

**输入**：一行三个整数 `a b p`（0 ≤ a, b ≤ 10^18，1 ≤ p ≤ 10^9）

**输出**：一个整数

**样例**

```text
输入：2 10 1000
输出：24
```

<details>
<summary>参考答案</summary>

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        long a = sc.nextLong(), b = sc.nextLong(), p = sc.nextLong();
        long res = 1 % p;
        a %= p;
        while (b > 0) {
            if ((b & 1) == 1) res = res * a % p;
            a = a * a % p;
            b >>= 1;
        }
        System.out.println(res);
    }
}
```

复杂度 O(log b)。

</details>

**满分要点**：`1 % p`（p = 1 时答案为 0）；先 `a %= p`；每步取模。
**常见失分**：b = 0 时返回 a；用 int 导致溢出；p = 1 没有特判。

### 练习 3 · 组合数（中）

求 `C(n, m) mod 1000000007`。

**输入**：一行两个整数 `n m`（0 ≤ m ≤ n ≤ 10^6）

**输出**：一个整数

**样例**

```text
输入：10 3
输出：120
```

<details>
<summary>参考答案</summary>

```java
import java.util.*;

public class Main {
    static final long MOD = 1_000_000_007L;

    static long pow(long a, long e) {
        long r = 1;
        a %= MOD;
        while (e > 0) {
            if ((e & 1) == 1) r = r * a % MOD;
            a = a * a % MOD;
            e >>= 1;
        }
        return r;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt(), m = sc.nextInt();
        long[] fact = new long[n + 1];
        long[] inv = new long[n + 1];
        fact[0] = 1;
        for (int i = 1; i <= n; i++) fact[i] = fact[i - 1] * i % MOD;
        inv[n] = pow(fact[n], MOD - 2);
        for (int i = n; i >= 1; i--) inv[i - 1] = inv[i] * i % MOD;
        long ans = fact[n] * inv[m] % MOD * inv[n - m] % MOD;
        System.out.println(ans);
    }
}
```

O(n) 预处理，O(1) 查询；多组询问时可复用数组。

</details>

**满分要点**：MOD 是质数才能用费马小定理；逆元阶乘倒推；`n - m` 下标。
**常见失分**：只预处理 fact 不预处理逆元；m = 0 或 m = n 时越界；MOD 写成 int。

## 6. AI 评分要点

- 乘法是否在取模前用 long（`a * b` 最大 10^18）。
- 0、1、p = 1 的边界是否处理。
- 筛法内层是否从 `i * i` 开始，`i * i` 是否溢出。
- 组合数是否只适用于质数模；非质数模需要 Lucas / exgcd，不能套这个模板。
- 负数取模是否规范化为正数。
