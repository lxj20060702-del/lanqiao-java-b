# 题型题库总览

每个题型是一章，固定结构：

1. **概念**：这个题型在解决什么问题，为什么有效
2. **如何识别**：题面特征 + 数据范围信号
3. **从低分到满分**：暴力解法 → 优化 → 最优解，附代码与复杂度
4. **模板**：考场可直接改写的骨架
5. **小试牛刀**：2~3 道题，含样例、提示、折叠的参考答案
6. **AI 评分要点**：本题型最容易丢分的地方

## 学习顺序

```
01 枚举与模拟  →  02 排序与贪心  →  03 前缀和与差分  →  04 二分与双指针
      ↓
05 搜索  →  06 动态规划  →  07 图论
      ↓
08 数论  →  09 字符串  →  10 数据结构
```

- 01~04 是省赛简单题的主力，必须全部拿满。
- 05~06 决定能否稳省一。
- 07~10 决定国赛和压轴题。

## 怎么用「解法演进」

每章的「从低分到满分」不是让你背两套代码，而是训练这种思维：

1. 先写暴力，确认自己理解对了，同时拿到部分分。
2. 找出暴力里的重复计算（同一个区间反复求和、同一状态反复枚举）。
3. 用数据结构或数学性质消除重复。
4. 对照数据范围，确认优化后的复杂度足够。

考场上先交暴力，再想优化——这是 OI 赛制下最稳的得分方式。
