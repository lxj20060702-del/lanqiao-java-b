# 题型 04 · 二分与双指针

> 一句话：**二分把「有序」变成 log；双指针把「两层枚举」压成一次扫描。**

## 1. 概念：这个题型在考什么

- 二分查找：在**有序**序列中每次排除一半，O(log n)。
- 二分答案：答案具有单调性时（越大越容易满足 / 越小越容易满足），直接对答案二分，把「求最优」变成「判断可行性」。
- 双指针：两个指针只朝一个方向移动，利用单调性把 O(n²) 降到 O(n)。
- 省赛地位：二分答案几乎每年都有；滑动窗口是字符串/子数组题的常客。

## 2. 如何识别

| 题面特征 | 判断 |
|---|---|
| 有序数组找某个值 / 第一个满足条件的位置 | 二分查找 |
| 求「最小的最大值」「最大的最小值」 | 二分答案 |
| 求「至少 / 至多满足某条件」的最小长度 | 滑动窗口 |
| 有序数组中找两数之和 | 双指针 |
| 答案范围大（10^9）但可以 O(n) 判断 | 二分答案 |

二分答案的三个前提：**答案在一个区间内**、**可以 O(n) 判断某个答案是否可行**、**可行性随答案单调**。

## 3. 从低分到满分

**例题**：在升序数组中找第一个大于等于 x 的下标（lower bound）。

### 3.1 线性扫描（小数据能过）

```java
int ans = n;
for (int i = 0; i < n; i++) {
    if (a[i] >= x) {
        ans = i;
        break;
    }
}
```

- O(n)，q 次询问就是 O(nq)。

### 3.2 满分解法：二分

```java
static int lowerBound(int[] a, int x) {
    int l = 0, r = a.length;          // 答案在 [0, n]
    while (l < r) {
        int mid = (l + r) >>> 1;
        if (a[mid] < x) {
            l = mid + 1;
        } else {
            r = mid;
        }
    }
    return l;                          // 第一个 >= x 的位置，可能等于 n
}
```

- 每次 O(log n)，q 次询问 O(q log n)。
- 用 `l < r` + `r = mid` 的写法，区间左闭右开，不容易死循环。

| 解法 | 复杂度 | 得分 |
|---|---|---|
| 线性扫描 | O(nq) | 小数据 |
| 二分 | O(q log n) | 满分 |

## 4. 二分答案模板

```java
long lo = 最小可能答案, hi = 最大可能答案;
while (lo < hi) {
    long mid = (lo + hi) >>> 1;
    if (可行(mid)) {
        hi = mid;          // 找最小可行值
    } else {
        lo = mid + 1;
    }
}
// lo 即答案
```

若求「最大可行值」，改成 `if (可行(mid)) lo = mid; else hi = mid - 1;`，并用 `(lo + hi + 1) >>> 1` 防死循环。

## 5. 小试牛刀

### 练习 1 · 切木头（中）

有 n 根木头，长度分别为 `L[i]`。要切出 **k 段长度相同**的木头，求每段的最大长度（整数）。

**输入**：第一行 `n k`（1 ≤ n ≤ 10^5，1 ≤ k ≤ 10^9）；第二行 n 个整数

**输出**：一个整数，表示最大长度；一段都切不出输出 0

**样例**

```text
输入：
3 7
10 24 15
输出：6
```

解释：长度 6 时可以切出 1 + 4 + 2 = 7 段；长度 7 时只有 1 + 3 + 2 = 6 段。

<details>
<summary>参考答案</summary>

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        long k = sc.nextLong();
        long[] len = new long[n];
        long hi = 0;
        for (int i = 0; i < n; i++) {
            len[i] = sc.nextLong();
            hi = Math.max(hi, len[i]);
        }
        long lo = 1, ans = 0;
        while (lo <= hi) {
            long mid = (lo + hi) >>> 1;
            long cnt = 0;
            for (long x : len) {
                cnt += x / mid;
                if (cnt >= k) break;      // 提前退出，防溢出
            }
            if (cnt >= k) {
                ans = mid;
                lo = mid + 1;
            } else {
                hi = mid - 1;
            }
        }
        System.out.println(ans);
    }
}
```

复杂度 O(n log maxL)。

</details>

**满分要点**：答案单调（长度越长段数越少）；上界取最长木头；cnt 用 long 且可提前 break。
**常见失分**：二分区间的开闭写错导致死循环；`x / mid` 当 mid 为 0；cnt 用 int 溢出。

### 练习 2 · 最短子数组（中）

给一个正整数数组和整数 s，求**和 ≥ s** 的最短连续子数组长度。不存在输出 0。

**输入**：第一行 `n s`；第二行 n 个正整数

**输出**：最短长度

**样例**

```text
输入：
6 7
2 3 1 2 4 3
输出：2
```

解释：4 + 3 = 7，长度 2。

<details>
<summary>参考答案</summary>

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        long s = sc.nextLong();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) a[i] = sc.nextInt();

        int left = 0, best = Integer.MAX_VALUE;
        long sum = 0;
        for (int right = 0; right < n; right++) {
            sum += a[right];
            while (sum >= s) {                 // 窗口满足条件就尝试收缩
                best = Math.min(best, right - left + 1);
                sum -= a[left++];
            }
        }
        System.out.println(best == Integer.MAX_VALUE ? 0 : best);
    }
}
```

复杂度 O(n)：每个元素最多被 left、right 各访问一次。

</details>

**满分要点**：正数保证单调性，窗口才能收缩；`while` 而不是 `if`；无解输出 0。
**常见失分**：数组含负数还用滑动窗口（不成立）；收缩时忘记减 sum；输出 0 的条件写错。

## 6. AI 评分要点

- 二分边界：`while (l < r)` 还是 `<=`，mid 取法是否与收缩方式匹配，会不会死循环。
- 二分答案的可行性函数是否真的单调，有没有漏掉「等于」的情况。
- 上界是否取到 `max(a)` 或 `sum(a)`，而不是随便写 10^9。
- 滑动窗口是否依赖「元素非负」这一前提。
- 求和、乘积是否 long。
