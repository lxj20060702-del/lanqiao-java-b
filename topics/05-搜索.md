# 题型 05 · 搜索

> 一句话：**DFS 一条路走到黑，BFS 一层层扩散，回溯在「选与不选」之间来回撤销。**

## 1. 概念：这个题型在考什么

- DFS：沿一条路径一直走，走不通再退回。适合连通块、方案枚举、可达性。
- BFS：从起点向外一层层扩展，第一次到达就是最短步数（边权都为 1）。
- 回溯：DFS 的一种，做选择 → 递归 → **撤销选择**，枚举所有方案。
- 剪枝：提前判断「这条路不可能更优 / 不合法」，直接返回，是搜索能否满分的关键。
- 省赛地位：网格题、棋盘题、排列组合题必考。

## 2. 如何识别

| 题面特征 | 判断 |
|---|---|
| 网格中从 A 到 B 的最少步数 | BFS |
| 求连通块数量 / 能否到达 | DFS 或 BFS |
| 输出所有方案、全排列、子集 | 回溯 |
| 棋盘放棋子、互不攻击 | 回溯 + 剪枝 |
| 状态空间小但层数深 | DFS + 剪枝 |

范围信号：方案类题目 n ≤ 10 才是搜索的范围；网格题 n, m ≤ 1000 用 BFS，注意队列大小。

## 3. 从低分到满分

**例题**：输出 1 ~ n 的所有排列。

### 3.1 暴力：n 层循环（只能处理固定 n）

```java
for (int a = 1; a <= 3; a++)
    for (int b = 1; b <= 3; b++)
        for (int c = 1; c <= 3; c++)
            if (a != b && a != c && b != c)
                System.out.println(a + " " + b + " " + c);
```

- 只能写死 n = 3，n 变化就要重写。
- 复杂度 O(n^n)，大部分是无效枚举。

### 3.2 满分：回溯

```java
static void dfs(int depth, int n, boolean[] used, int[] cur) {
    if (depth == n) {
        // 输出 cur
        return;
    }
    for (int x = 1; x <= n; x++) {
        if (used[x]) continue;
        used[x] = true;          // 做选择
        cur[depth] = x;
        dfs(depth + 1, n, used, cur);
        used[x] = false;         // 撤销选择
    }
}
```

- 复杂度 O(n! · n)，但只枚举合法方案。
- 关键：**递归前标记，递归后恢复**，否则后面的分支会被污染。

| 解法 | 复杂度 | 得分 |
|---|---|---|
| n 层循环 | O(n^n) | 只能固定 n |
| 回溯 | O(n! · n) | 满分（n ≤ 10） |

## 4. BFS 模板（网格最短路）

```java
int[] dx = {-1, 1, 0, 0};
int[] dy = {0, 0, -1, 1};
int[][] dist = new int[n][m];
for (int[] row : dist) Arrays.fill(row, -1);
Deque<int[]> q = new ArrayDeque<>();
dist[0][0] = 0;
q.offer(new int[]{0, 0});
while (!q.isEmpty()) {
    int[] cur = q.poll();
    for (int d = 0; d < 4; d++) {
        int nx = cur[0] + dx[d], ny = cur[1] + dy[d];
        if (nx >= 0 && nx < n && ny >= 0 && ny < m
                && grid[nx][ny] == 0 && dist[nx][ny] == -1) {
            dist[nx][ny] = dist[cur[0]][cur[1]] + 1;
            q.offer(new int[]{nx, ny});
        }
    }
}
```

## 5. 小试牛刀

### 练习 1 · 迷宫最短路（易）

n × m 的网格，0 表示空地，1 表示墙。从 `(1,1)` 走到 `(n,m)`，只能上下左右移动，求最少步数。无法到达输出 -1。

**输入**：第一行 `n m`；接下来 n 行每行 m 个 0/1

**输出**：最少步数或 -1

**样例**

```text
输入：
3 3
0 0 0
0 1 0
0 0 0
输出：4
```

<details>
<summary>参考答案</summary>

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt(), m = sc.nextInt();
        int[][] g = new int[n][m];
        for (int i = 0; i < n; i++)
            for (int j = 0; j < m; j++)
                g[i][j] = sc.nextInt();

        if (g[0][0] == 1) {
            System.out.println(-1);
            return;
        }
        int[][] dist = new int[n][m];
        for (int[] row : dist) Arrays.fill(row, -1);
        int[] dx = {-1, 1, 0, 0}, dy = {0, 0, -1, 1};
        Deque<int[]> q = new ArrayDeque<>();
        dist[0][0] = 0;
        q.offer(new int[]{0, 0});
        while (!q.isEmpty()) {
            int[] cur = q.poll();
            if (cur[0] == n - 1 && cur[1] == m - 1) break;
            for (int d = 0; d < 4; d++) {
                int nx = cur[0] + dx[d], ny = cur[1] + dy[d];
                if (nx >= 0 && nx < n && ny >= 0 && ny < m
                        && g[nx][ny] == 0 && dist[nx][ny] == -1) {
                    dist[nx][ny] = dist[cur[0]][cur[1]] + 1;
                    q.offer(new int[]{nx, ny});
                }
            }
        }
        System.out.println(dist[n - 1][m - 1]);
    }
}
```

复杂度 O(nm)。

</details>

**满分要点**：BFS 第一次到达即最短；入队时就标记 visited，避免重复入队；起点是墙的特判。
**常见失分**：用 DFS 求最短路（不保证最短）；出队才标记导致重复入队、TLE；忘记判断 0-indexed 边界。

### 练习 2 · N 皇后（中）

在 n × n 棋盘上放 n 个皇后，任意两个不能同行、同列、同对角线。求方案数。

**输入**：一个整数 n（1 ≤ n ≤ 12）

**输出**：方案数

**样例**

```text
输入：4
输出：2
```

<details>
<summary>参考答案</summary>

```java
import java.util.*;

public class Main {
    static int n, count = 0;

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        n = sc.nextInt();
        dfs(0, new boolean[n], new boolean[2 * n], new boolean[2 * n]);
        System.out.println(count);
    }

    static void dfs(int row, boolean[] col, boolean[] d1, boolean[] d2) {
        if (row == n) {
            count++;
            return;
        }
        for (int c = 0; c < n; c++) {
            if (col[c] || d1[row + c] || d2[row - c + n]) continue;
            col[c] = d1[row + c] = d2[row - c + n] = true;
            dfs(row + 1, col, d1, d2);
            col[c] = d1[row + c] = d2[row - c + n] = false;
        }
    }
}
```

复杂度约为 O(n!)，n = 12 时借助剪枝可以跑完。

</details>

**满分要点**：三个方向的冲突数组；对角线编号 `row+c` 和 `row-c+n`；递归后恢复现场。
**常见失分**：只判列不判对角线；`row-c` 为负导致下标越界；忘记恢复导致方案数偏少。

## 6. AI 评分要点

- BFS 和 DFS 是否用对：**最短路必须 BFS**。
- visited 标记时机：BFS 入队时标记，回溯时递归后恢复。
- 递归深度是否可能超过 10^4（会栈溢出），是否需要改迭代。
- 是否有剪枝；没有剪枝的搜索在 n = 12 以上可能 TLE。
- 队列是否用了 `ArrayDeque`，而不是 `LinkedList` 或 `Stack`。
