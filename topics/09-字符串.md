# 题型 09 · 字符串

> 一句话：**暴力匹配是 O(nm)，KMP 利用「已匹配信息」做到 O(n+m)，哈希把子串比较变成 O(1)。**

## 1. 概念：这个题型在考什么

- 子串（连续）vs 子序列（不连续）——先分清，解法完全不同。
- 暴力匹配：对每个起点逐字符比较，最坏 O(nm)。
- KMP：预处理模式串的 `next`（前缀函数），失配时跳到已匹配的前缀，O(n+m)。
- 字符串哈希：把子串映射成数字，判等 O(1)，但存在碰撞风险。
- 回文：中心扩展 O(n²)、Manacher O(n)（省赛很少需要）。
- 省赛地位：统计、匹配、回文、字符计数，多为中低档题。

## 2. 如何识别

| 题面特征 | 判断 |
|---|---|
| 统计模式串出现次数 / 第一次出现 | KMP 或 `indexOf` |
| 判断两个子串是否相等、多次比较 | 字符串哈希 |
| 最长回文子串 / 回文判断 | 中心扩展 |
| 字符出现次数、异位词 | 计数数组 |
| 两个字符串的公共部分 | LCS（DP） |

范围信号：n ≤ 10^3 可以暴力；n ≤ 10^5 必须 KMP 或哈希；多次子串判等用哈希。

## 3. 从低分到满分

**例题**：在文本串中查找模式串第一次出现的位置。

### 3.1 暴力匹配（小数据能过）

```java
for (int i = 0; i + m <= n; i++) {
    int j = 0;
    while (j < m && text.charAt(i + j) == pattern.charAt(j)) j++;
    if (j == m) return i;
}
```

- 最坏 O(nm)，例如 `text = "aaaa...a"`、`pattern = "aaab"`。

### 3.2 满分：KMP

`pi[i]` 表示 `pattern[0..i]` 的最长相等前后缀长度。

```java
static int[] prefixFunction(String s) {
    int n = s.length();
    int[] pi = new int[n];
    for (int i = 1; i < n; i++) {
        int j = pi[i - 1];
        while (j > 0 && s.charAt(i) != s.charAt(j)) j = pi[j - 1];
        if (s.charAt(i) == s.charAt(j)) j++;
        pi[i] = j;
    }
    return pi;
}

static int indexOf(String text, String pattern) {
    int[] pi = prefixFunction(pattern);
    int j = 0;
    for (int i = 0; i < text.length(); i++) {
        while (j > 0 && text.charAt(i) != pattern.charAt(j)) j = pi[j - 1];
        if (text.charAt(i) == pattern.charAt(j)) j++;
        if (j == pattern.length()) return i - pattern.length() + 1;
    }
    return -1;
}
```

- O(n + m)，n、m 到 10^6 也能过。

| 解法 | 复杂度 | 得分 |
|---|---|---|
| 暴力 | O(nm) | 小数据 |
| KMP | O(n + m) | 满分 |

## 4. 字符串哈希模板

```java
long[] h = new long[n + 1], pow = new long[n + 1];
pow[0] = 1;
for (int i = 0; i < n; i++) {
    h[i + 1] = (h[i] * BASE + s.charAt(i)) % MOD;
    pow[i + 1] = pow[i] * BASE % MOD;
}
// 子串 s[l..r) 的哈希
long hash = (h[r] - h[l] * pow[r - l] % MOD + MOD) % MOD;
```

`BASE = 131`、`MOD = 1_000_000_007` 是常用组合。比赛里若不放心碰撞，可用双哈希。

## 5. 小试牛刀

### 练习 1 · 统计出现次数（易）

给文本串 text 和模式串 pattern，统计 pattern 在 text 中出现的次数（**允许重叠**）。

**输入**：两行，分别是 text 和 pattern（长度 ≤ 10^6）

**输出**：出现次数

**样例**

```text
输入：
aaaaa
aa
输出：4
```

<details>
<summary>参考答案</summary>

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String text = sc.nextLine();
        String pattern = sc.nextLine();
        int[] pi = prefixFunction(pattern);
        int j = 0, count = 0;
        for (int i = 0; i < text.length(); i++) {
            while (j > 0 && text.charAt(i) != pattern.charAt(j)) j = pi[j - 1];
            if (text.charAt(i) == pattern.charAt(j)) j++;
            if (j == pattern.length()) {
                count++;
                j = pi[j - 1];        // 允许重叠，回退到前缀
            }
        }
        System.out.println(count);
    }

    static int[] prefixFunction(String s) {
        int n = s.length();
        int[] pi = new int[n];
        for (int i = 1; i < n; i++) {
            int j = pi[i - 1];
            while (j > 0 && s.charAt(i) != s.charAt(j)) j = pi[j - 1];
            if (s.charAt(i) == s.charAt(j)) j++;
            pi[i] = j;
        }
        return pi;
    }
}
```

</details>

**满分要点**：匹配成功后 `j = pi[j-1]` 才能继续找重叠；用 `charAt` 而不是 `substring`。
**常见失分**：匹配成功后把 j 清零（漏掉重叠）；每轮 `substring` 比较导致 O(nm) 和大量对象。

### 练习 2 · 最长回文子串（中）

给字符串 s，求最长回文子串的长度。

**输入**：一行字符串 s（长度 ≤ 5000）

**输出**：最长长度

**样例**

```text
输入：babad
输出：3
```

解释：`bab` 或 `aba` 都是长度 3 的回文。

<details>
<summary>参考答案</summary>

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String s = sc.nextLine();
        int best = 1;
        for (int c = 0; c < s.length(); c++) {
            best = Math.max(best, expand(s, c, c));       // 奇数长度
            best = Math.max(best, expand(s, c, c + 1));   // 偶数长度
        }
        System.out.println(best);
    }

    static int expand(String s, int l, int r) {
        while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) {
            l--;
            r++;
        }
        return r - l - 1;
    }
}
```

O(n²)，n = 5000 约 2.5×10^7 次比较。

</details>

**满分要点**：奇偶两种中心都要枚举；返回 `r - l - 1`；单字符答案是 1。
**常见失分**：只枚举奇数中心；返回值算成 `r - l + 1`；空串没处理。

## 6. AI 评分要点

- 题目要的是子串（连续）还是子序列（不连续）。
- `String` 比较是否用了 `equals`；循环里是否频繁 `substring`。
- KMP 的 `pi` 数组边界、匹配成功后是否回退。
- 回文的奇偶中心是否都覆盖。
- 哈希是否只用了单哈希，是否有人为构造碰撞的风险。
