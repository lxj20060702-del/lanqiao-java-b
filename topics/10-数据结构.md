# 题型 10 · 数据结构

> 一句话：**用结构换时间——单调栈解决「下一个更大」，树状数组解决「边改边查」。**

## 1. 概念：这个题型在考什么

- 单调栈：维护一个单调的栈，O(n) 求「左边/右边第一个更大/更小」。
- 单调队列：滑动窗口最值，O(n)。
- 树状数组：单点修改 + 前缀和，O(log n)，代码短。
- 线段树：区间修改 + 区间查询，O(log n)，功能强但代码长。
- 优先队列：动态取最值。
- 省赛地位：单调栈/队列常作为压轴题的优化手段；树状数组是「暴力超时」后的第一选择。

## 2. 如何识别

| 题面特征 | 判断 |
|---|---|
| 找每个元素右边第一个更大的数 | 单调栈 |
| 滑动窗口的最大值 / 最小值 | 单调队列 |
| 多次单点修改 + 区间求和 | 树状数组 |
| 区间加 + 区间求和 | 线段树 |
| 动态维护第 k 大 | 优先队列 / 平衡树 |
| 前缀匹配、异或最大值 | Trie |

范围信号：n、q ≤ 10^5 且暴力 O(nq) 超时 → 树状数组 / 线段树 / 单调结构。

## 3. 从低分到满分

**例题**：对每个元素，求它右边第一个比它大的数。

### 3.1 暴力（小数据能过）

```java
for (int i = 0; i < n; i++) {
    int ans = -1;
    for (int j = i + 1; j < n; j++) {
        if (a[j] > a[i]) {
            ans = a[j];
            break;
        }
    }
}
```

- O(n²)，n = 10^5 时 10^10，必超时。

### 3.2 满分：单调栈

维护一个**递减**栈，栈里存下标。当前元素比栈顶大，就说明栈顶的答案找到了。

```java
static int[] nextGreater(int[] a) {
    int n = a.length;
    int[] res = new int[n];
    Arrays.fill(res, -1);
    Deque<Integer> st = new ArrayDeque<>();     // 存下标
    for (int i = 0; i < n; i++) {
        while (!st.isEmpty() && a[st.peek()] < a[i]) {
            res[st.pop()] = a[i];
        }
        st.push(i);
    }
    return res;
}
```

- O(n)：每个元素最多入栈、出栈各一次。

| 解法 | 复杂度 | 得分 |
|---|---|---|
| 暴力 | O(n²) | 小数据 |
| 单调栈 | O(n) | 满分 |

## 4. 树状数组模板

```java
static int n;
static long[] tree;

static void add(int i, long delta) {
    for (; i <= n; i += i & -i) tree[i] += delta;
}

static long prefixSum(int i) {
    long sum = 0;
    for (; i > 0; i -= i & -i) sum += tree[i];
    return sum;
}

static long rangeSum(int l, int r) {
    return prefixSum(r) - prefixSum(l - 1);
}
```

注意：树状数组下标**从 1 开始**。

## 5. 小试牛刀

### 练习 1 · 下一个更大元素（易）

给数组 a，对每个 `a[i]` 输出它右边第一个比它大的数；不存在输出 -1。

**输入**：第一行 n；第二行 n 个整数

**输出**：一行 n 个整数

**样例**

```text
输入：
4
2 1 3 4
输出：3 3 4 -1
```

<details>
<summary>参考答案</summary>

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) a[i] = sc.nextInt();

        int[] res = new int[n];
        Arrays.fill(res, -1);
        Deque<Integer> st = new ArrayDeque<>();
        for (int i = 0; i < n; i++) {
            while (!st.isEmpty() && a[st.peek()] < a[i]) {
                res[st.pop()] = a[i];
            }
            st.push(i);
        }

        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < n; i++) {
            if (i > 0) sb.append(' ');
            sb.append(res[i]);
        }
        System.out.println(sb);
    }
}
```

</details>

**满分要点**：栈里存**下标**而不是值；严格大于用 `<`，非严格用 `<=`；最后统一输出。
**常见失分**：栈里存值导致找不到原位置；比较符号写反变成「下一个更小」；输出格式多空格。

### 练习 2 · 树状数组（中）

长度 n 的数组，初始为 `a[1..n]`。q 次操作：

- `1 i v`：把 `a[i]` 加上 v
- `2 l r`：输出 `a[l] + ... + a[r]`

**输入**：第一行 `n q`；第二行 n 个整数；接下来 q 行操作

**输出**：每个 2 操作输出一行

**样例**

```text
输入：
5 3
1 2 3 4 5
1 2 3
2 1 3
2 2 5
输出：
9
17
```

<details>
<summary>参考答案</summary>

```java
import java.util.*;

public class Main {
    static int n;
    static long[] tree;

    static void add(int i, long delta) {
        for (; i <= n; i += i & -i) tree[i] += delta;
    }

    static long prefixSum(int i) {
        long sum = 0;
        for (; i > 0; i -= i & -i) sum += tree[i];
        return sum;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        n = sc.nextInt();
        int q = sc.nextInt();
        tree = new long[n + 1];
        for (int i = 1; i <= n; i++) {
            add(i, sc.nextLong());          // 初始值用单点加建树，O(n log n)
        }

        StringBuilder sb = new StringBuilder();
        while (q-- > 0) {
            int type = sc.nextInt();
            if (type == 1) {
                add(sc.nextInt(), sc.nextLong());
            } else {
                int l = sc.nextInt(), r = sc.nextInt();
                sb.append(prefixSum(r) - prefixSum(l - 1)).append('\n');
            }
        }
        System.out.print(sb);
    }
}
```

如需更快的建树，可以 O(n) 直接构造：`tree[i] += a[i]; tree[i + (i & -i)] += tree[i]`。

</details>

**满分要点**：下标从 1 开始；`i & -i` 的写法；查询用 `pre[r] - pre[l-1]`；long。
**常见失分**：用 0 下标导致死循环；修改和查询方向写反（`+=` / `-=`）；前缀和减错区间。

## 6. AI 评分要点

- 树状数组下标是否从 1 开始，`i & -i` 是否正确。
- 单调栈里存的是下标还是值，比较符号与题意是否一致。
- 是否有 O(n²) 的暴力没有被优化。
- 数据量 10^5 时，`Scanner` 是否成为瓶颈（可换 `FastIO`）。
- 修改、查询是否用了 long，是否每步取模（若题目要求）。
