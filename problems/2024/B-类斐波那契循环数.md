# 2024 省赛 Java B 组 B - 类斐波那契循环数

> 题面来源：https://www.dotcpp.com/oj/1118/。题面版权归蓝桥杯大赛组委会所有，此处仅用于学习交流。

## 题目

### 问题描述

对于一个有 n 位的十进制数 `N = d1 d2 d3 ... dn`，可以生成一个类斐波那契数列 S，数列 S 的前 n 个数为 `{S1 = d1, S2 = d2, S3 = d3, ..., Sn = dn}`，数列 S 的第 k（k > n）个数为 `Σ_{i=k-n}^{k-1} S_i`。如果这个数 N 会出现在对应的类斐波那契数列 S 中，那么 N 就是一个类斐波那契循环数。

例如对于 197，对应的数列 S 为 `{1, 9, 7, 17, 33, 57, 107, 197, ...}`，197 出现在 S 中，所以 197 是一个类斐波那契循环数。

请问在 0 至 10^7 中，最大的类斐波那契循环数是多少？

### 答案提交

这是一道结果填空的题，你只需要算出结果后提交即可。本题的结果为一个整数，在提交答案时只填写这个整数，填写多余的内容将无法得分。

## 思路

1. 对每个候选 N，取出它的 n 位数字作为数列前 n 项，并维护一个长度为 n 的滑动窗口和 `sum`。初始时 `sum = 各位数字之和`，它正好是 `S_{n+1}`。
2. 依次向后生成：每得到当前项 `sum`，先判断它是否等于 N；若等于则 N 是类斐波那契循环数；若 `sum > N` 则停止。
3. 滑动一步：`sum = sum - 窗口最旧项 + 新项`，并把最旧项替换为新项。
4. **为什么可以一旦超过 N 就停止**：从 `S_{n+1}` 起数列严格递增。因为 `S_{n+1}` 为各位数字之和，至少为 `d1 + dn > dn`（d1 ≥ 1），所以 `S_{n+1} > S_n`；之后由 `S_{k+1} - S_k = S_k - S_{k-n}`，一旦开始递增便保持递增。因此超过 N 后不可能再回到 N。
5. 从 `10^7` 向下枚举，第一个满足条件的数即为答案（一位数天然满足，因为 `S1 = N`，但显然不是最大）。

运行结果：**7913837**。

## 代码

```java
public class Main {
    // 判断 x 是否为类斐波那契循环数
    static boolean isLoop(long x) {
        if (x == 0) return true; // 0 的数列为 0,0,...，0 出现
        // 取出各位数字
        int[] d = new int[20];
        int n = 0;
        long t = x;
        while (t > 0) {
            d[n++] = (int) (t % 10);
            t /= 10;
        }
        // 反转成高位在前
        for (int i = 0, j = n - 1; i < j; i++, j--) {
            int tmp = d[i];
            d[i] = d[j];
            d[j] = tmp;
        }
        // 维护长度为 n 的滑动窗口和，初值为各位数字之和
        long sum = 0;
        for (int i = 0; i < n; i++) sum += d[i];
        // 依次检查每个新项；从第 n+1 项开始严格递增
        int head = 0; // 窗口中最早一项的下标（相对 d 的环形位置）
        long[] win = new long[n];
        for (int i = 0; i < n; i++) win[i] = d[i];
        while (true) {
            if (sum == x) return true;
            if (sum > x) return false;
            long next = sum;
            // 窗口右移：去掉 win[head]，加入 next
            sum = sum - win[head] + next;
            win[head] = next;
            head = (head + 1) % n;
        }
    }

    public static void main(String[] args) {
        long limit = 10000000L;
        long ans = -1;
        for (long x = limit; x >= 0; x--) {
            if (isLoop(x)) {
                ans = x;
                break;
            }
        }
        System.out.println(ans);
    }
}
```

## 复杂度

- 时间：`O(10^7 · L)`，其中 `L` 是生成到超过 N 所需的项数，通常约 20 项；实测约 0.35 秒。
- 空间：`O(L)`，即 `O(n)` 的窗口数组，n ≤ 8。

## 易错点

1. **忘记一位数天然满足**：n = 1 时 `S1 = d1 = N`，所有一位数都是类斐波那契循环数，但答案不会是它们。
2. **窗口滑动写错**：`S_{n+1}` 是前 n 位数字之和，此后每次窗口右移一位，别把新项重复加入。
3. **停止条件**：数列从 `S_{n+1}` 起严格递增，`sum > N` 即可退出；否则可能死循环。
4. **0 的处理**：0 的各位数字为 0，数列为全 0，按定义 0 也满足；本题求最大值，不影响结果。
5. **数字顺序**：取模得到的是低位在前，需反转为高位在前，否则数列初值顺序错误。
