# 2024 省赛 Java B 组 A - 报数游戏

> 题面来源：https://www.dotcpp.com/oj/1118/。题面版权归蓝桥杯大赛组委会所有，此处仅用于学习交流。

## 题目

### 问题描述

小蓝和朋友们在玩一个报数游戏。由于今年是 2024 年，他们决定要从小到大轮流报出是 20 或 24 倍数的正整数。前 10 个被报出的数是：20; 24; 40; 48; 60; 72; 80; 96; 100; 120。请问第 202420242024 个被报出的数是多少？

### 答案提交

这是一道结果填空的题，你只需要算出结果后提交即可。本题的结果为一个整数，在提交答案时只填写这个整数，填写多余的内容将无法得分。

## 思路

1. 设 `f(x)` 表示 `[1, x]` 中有多少个正整数是 20 或 24 的倍数。由容斥原理：
   `f(x) = x/20 + x/24 - x/120`，其中 120 是 20 与 24 的最小公倍数。
2. 20 或 24 的倍数的“密度”为 `1/20 + 1/24 - 1/120 = 1/12`，因此第 `k = 202420242024` 个数约为 `12k`。
3. 由于 `f(x)` 单调不减，且题目要求的数唯一，可以对 `x` 做二分：找到最小的 `x` 使得 `f(x) >= k`。此时 `f(x-1) = k-1`，`x` 恰好是第 `k` 个被报出的数。
4. 正确性：`f` 统计的正是从小到大排列的报数序列的前缀长度；满足 `f(x) >= k` 的最小 `x` 就是序列第 `k` 项。

答案为：**2429042904288**。

## 代码

```java
public class Main {
    // 统计 [1, x] 中能被 20 或 24 整除的整数个数
    static long count(long x) {
        if (x <= 0) return 0;
        return x / 20 + x / 24 - x / 120; // 容斥，lcm(20,24)=120
    }

    public static void main(String[] args) {
        long k = 202420242024L;
        // 二分最小的 x 使 count(x) >= k
        long lo = 1, hi = k * 12 + 100; // 密度约为 1/12
        while (lo < hi) {
            long mid = lo + (hi - lo) / 2;
            if (count(mid) >= k) hi = mid;
            else lo = mid + 1;
        }
        System.out.println(lo);
        System.out.println("count(lo-1)=" + count(lo - 1) + ", count(lo)=" + count(lo));
        System.out.println("lo%20=" + (lo % 20) + ", lo%24=" + (lo % 24));
    }
}
```

## 复杂度

- 时间：`O(log(answer))`，约 45 次二分。
- 空间：`O(1)`。

## 易错点

1. **int 溢出**：第 202420242024 个数约为 `2.43 × 10^12`，远超 `int`，必须用 `long`。
2. **容斥时最小公倍数写错**：20 与 24 的 lcm 是 120，不是 480。
3. **误读“或”**：只要被 20 或 24 之一整除即可，不需要同时被两者整除；答案 `2429042904288` 只被 24 整除。
4. **二分边界**：上界要足够大，可用 `12 * k + 常数`；判断条件用 `f(mid) >= k`。
5. **下标从 1 开始**：第 k 个对应 `f(x) = k`，不是 `k + 1`。
