# 2025 省赛 Java B 组 B - 消失的蓝宝

> 题面来源：https://www.dotcpp.com/oj/1164/。题面版权归蓝桥杯大赛组委会所有，此处仅用于学习交流。

## 题目

### 问题描述

“蓝宝又不见了！” 2025 年 4 月 12 日，蓝桥杯吉祥物 “蓝宝” 在省赛前夕突然失踪。小蓝翻阅了蓝宝的活动记录，发现它的出现时间似乎与蓝桥杯的两个重要日期密切相关：

第十六届省赛日期 20250412。

第十五届省赛日期 20240413。

经过分析，小蓝推测蓝宝的下一次出现时间 N 满足以下条件：

1. N + 20250412 能被 20240413 整除。
2. N + 20240413 能被 20250412 整除。

现在，请你帮小蓝找出满足条件的最小正整数 N，预测蓝宝的下一次出现时间。

### 答案提交

这是一道结果填空的题，你只需要算出结果后提交即可。本题的结果为一个整数，在提交答案时只填写这个整数，填写多余的内容将无法得分。

## 思路

1. 把两个条件改写成同余式：

   - `N + 20250412 ≡ 0 (mod 20240413)`，即 `N ≡ -20250412 ≡ 20230414 (mod 20240413)`；
   - `N + 20240413 ≡ 0 (mod 20250412)`，即 `N ≡ -20240413 ≡ 9999 (mod 20250412)`。

2. 设 `N = 20230414 + 20240413 × t`（`t ≥ 0`），代入第二个同余式，枚举 `t` 找到最小的正整数解。
3. 两个模数互质，因此解在模 `20240413 × 20250412` 下唯一，枚举 `t` 至多 `20250412` 次一定能找到答案。实际找到 `t = 20250409`，对应
   `N = 409876661809331`。
4. 回代校验：`(N + 20250412) mod 20240413 = 0`，`(N + 20240413) mod 20250412 = 0`。

## 代码

```java
public class Main {
    public static void main(String[] args) {
        long m1 = 20240413L;
        long m2 = 20250412L;
        // N + 20250412 能被 20240413 整除
        long a1 = (m1 - 20250412L % m1) % m1;
        // N + 20240413 能被 20250412 整除
        long a2 = (m2 - 20240413L % m2) % m2;
        // N = a1 + m1 * t，枚举 t 找到最小正整数解
        for (long t = 0; ; t++) {
            long n = a1 + m1 * t;
            if (n > 0 && n % m2 == a2) {
                System.out.println(n);
                break;
            }
        }
    }
}
```

## 复杂度

- 时间：最坏 `O(20250412)`，约 `2 × 10^7` 次枚举，实际很快找到解。
- 空间：`O(1)`。

## 易错点

- `N` 约为 `4.1 × 10^14`，必须使用 `long`，`int` 会溢出。
- 两个日期与两个模数容易混淆，交换后答案不同。
- 负数取模要写成 `(m - x % m) % m`，不能直接写 `-x % m`。
- 题目要求最小正整数，枚举时注意跳过非正数。
- 结果填空只提交整数 `409876661809331`。

## 验证

运行上述程序（无输入），实际输出：

```text
409876661809331
```

回代检查：`(409876661809331 + 20250412) % 20240413 = 0`，`(409876661809331 + 20240413) % 20250412 = 0`，两个条件同时成立。
