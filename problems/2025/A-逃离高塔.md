# 2025 省赛 Java B 组 A - 逃离高塔

> 题面来源：https://www.dotcpp.com/oj/1164/。题面版权归蓝桥杯大赛组委会所有，此处仅用于学习交流。

## 题目

### 问题描述

小蓝一觉醒来，发现自己被困在一座高耸的塔中。这座塔共有 2025 层，每一层都刻有一个数字的立方值，从底层的 1³、2³、3³、……，一直到顶层的 2025³，层层叠叠，直入云霄。塔顶有一扇门，门旁刻着一行字：“若想离开此塔，需找出这些立方数中个位数字为 3 的数的个数。”

小蓝非常着急，因为他需要尽快离开这座塔，去参加即将到来的蓝桥杯比赛。时间紧迫，请你帮助他解答这个问题。

### 答案提交

这是一道结果填空的题，你只需要算出结果后提交即可。本题的结果为一个整数，在提交答案时只填写这个整数，填写多余的内容将无法得分。

## 思路

1. 一个数的立方的个位只取决于它本身的个位：若 `i mod 10 = d`，则 `i³ mod 10 = d³ mod 10`。
2. 枚举 `d = 0..9`，`d³ mod 10` 依次为 `0,1,8,7,4,5,6,3,2,9`，只有 `d = 7` 时个位为 3。
3. 因此问题等价于统计 `1..2025` 中个位为 7 的整数：`7, 17, ..., 2017`，共 `(2017 - 7) / 10 + 1 = 202` 个。
4. 直接循环枚举 `i = 1..2025` 并计算 `i³` 的个位同样可行，下面的程序采用这种写法。

## 代码

```java
public class Main {
    public static void main(String[] args) {
        int ans = 0;
        for (int i = 1; i <= 2025; i++) {
            long cube = (long) i * i * i;
            if (cube % 10 == 3) {
                ans++;
            }
        }
        System.out.println(ans);
    }
}
```

## 复杂度

- 时间：`O(2025)`，即常数级。
- 空间：`O(1)`。

## 易错点

- `int` 计算 `i * i * i` 会溢出（2025³ 约为 `8.3 × 10^9`），必须转成 `long` 或只计算个位。
- 循环范围是 `1..2025`；写成 `0..2025` 不影响答案，但统计端点时要看清题意。
- 立方个位的周期是 10，不要只验证前几个数就下结论。
- 本题是结果填空，最终只填整数 `202`，不要附带其他文字。

## 验证

运行上述程序（无输入），实际输出：

```text
202
```

与手算 `(2017 - 7) / 10 + 1 = 202` 一致。
