# 2025 省赛 Java B 组 G - 2 的幂

> 题面来源：https://www.dotcpp.com/oj/problem3317.html。题面版权归蓝桥杯大赛组委会所有，此处仅用于学习交流。

## 题目

### 问题描述

小明很喜欢 2 的幂，所以他想对一个长度为 n 的正整数数组 {a₁, a₂, ..., aₙ} 进行改造。他可以进行如下操作任意多次（可以是 0 次）：任选一个数 aᵢ 加上任意正整数，但不能使得加完之后的结果超过 10⁵。

在操作任意次后，小明希望所有数的乘积是 2ᵏ 的倍数。他想知道总共需要加的数的总和至少是多少？

### 输入格式

输入共两行。

第一行为两个正整数 n, k。

第二行为 n 个由空格分开的正整数 a₁, a₂, ..., aₙ。

### 输出格式

输出共 1 行，一个整数表示答案。如果不能满足条件，输出 −1。

### 样例输入

```text
3 9
19 10 3
```

### 样例输出

```text
12
```

### 样例说明

将三个数分别加到 24, 16, 4，它们的乘积为 1536 = 2⁹ × 3，加的数的总和为 5 + 6 + 1 = 12。

### 评测用例规模与约定

对于 20% 的评测用例，`n, k ≤ 10`。

对于 100% 的评测用例，`n ≤ 500`，`k ≤ 5000`，`ai ≤ 100000`。

## 思路

1. 一个数 `x` 对乘积中因子 2 的贡献是 `v2(x)`（即 `x` 最多能被 2 的多少次幂整除）。所有数贡献之和至少为 `k` 时，乘积才是 `2^k` 的倍数。
2. 对单个 `aᵢ`，如果想让它贡献至少 `g` 个因子 2，最小的做法是把它增加到不小于 `aᵢ` 的最小的 `2^g` 的倍数：
   `x = ceil(aᵢ / 2^g) × 2^g`，代价为 `x - aᵢ`；若 `x > 10^5` 则该 `g` 不可行。
3. 因为 `2^17 = 131072 > 10^5`，任何不超过 `10^5` 的正整数最多含 16 个因子 2，所以只需考虑 `g = 0..16`（`g = 0` 时代价为 0）。
4. 以“已经累计的因子 2 个数”为状态做分组背包：`dp[j]` 表示累计至少 `j` 个因子 2 的最小总代价。每处理一个 `aᵢ`，枚举它的贡献 `g`，把 `dp[j] + cost[g]` 转移到 `min(k, j+g)`。
5. 最后 `dp[k]` 就是答案；若仍为无穷大则输出 `-1`。

## 代码

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.Arrays;
import java.util.StringTokenizer;

public class Main {
    static class FastReader {
        BufferedReader br;
        StringTokenizer st;

        FastReader() {
            br = new BufferedReader(new InputStreamReader(System.in));
        }

        String next() {
            while (st == null || !st.hasMoreTokens()) {
                try {
                    String line = br.readLine();
                    if (line == null) return null;
                    st = new StringTokenizer(line);
                } catch (IOException e) {
                    throw new RuntimeException(e);
                }
            }
            return st.nextToken();
        }

        int nextInt() {
            return Integer.parseInt(next());
        }
    }

    static final int LIMIT = 100000;
    static final int MAXG = 16;
    static final long INF = Long.MAX_VALUE / 4;

    public static void main(String[] args) {
        FastReader in = new FastReader();
        int n = in.nextInt();
        int k = in.nextInt();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) {
            a[i] = in.nextInt();
        }

        long[] dp = new long[k + 1];
        Arrays.fill(dp, INF);
        dp[0] = 0;

        for (int idx = 0; idx < n; idx++) {
            long[] cost = new long[MAXG + 1];
            for (int g = 0; g <= MAXG; g++) {
                long p = 1L << g;
                long x = ((a[idx] + p - 1) / p) * p;
                cost[g] = (x <= LIMIT) ? (x - a[idx]) : INF;
            }

            long[] ndp = new long[k + 1];
            Arrays.fill(ndp, INF);
            for (int j = 0; j <= k; j++) {
                if (dp[j] >= INF) continue;
                for (int g = 0; g <= MAXG; g++) {
                    if (cost[g] >= INF) continue;
                    int nj = Math.min(k, j + g);
                    long val = dp[j] + cost[g];
                    if (val < ndp[nj]) ndp[nj] = val;
                }
            }
            dp = ndp;
        }

        System.out.println(dp[k] >= INF ? -1 : dp[k]);
    }
}
```

## 复杂度

- 时间：`O(n × k × 17)`，最坏约 `500 × 5000 × 17 ≈ 4.3 × 10^7`。
- 空间：`O(k)`。

## 易错点

- 单个数的因子 2 个数最多为 16（`65536`），循环上界不要开到 17 以上还继续计算可行代价。
- 计算 `2^g` 与向上取整后的倍数时使用 `long`，避免边界溢出。
- 累计因子数超过 `k` 时可以直接按 `k` 处理，减少状态。
- `k = 0` 时答案为 0；根本无法达到 `k` 时输出 `-1`。
- 无穷大不要用 `Long.MAX_VALUE` 直接相加，否则会溢出，应使用足够大的有限值。

## 验证

使用题面样例输入运行，实际输出：

```text
12
```

与样例输出一致（19→24、10→16、3→4，总增量 5 + 6 + 1 = 12）。另外用小规模暴力枚举对照过随机数据，结果一致。
