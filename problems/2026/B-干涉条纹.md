# 2026 省赛 Java B 组 B - 干涉条纹

> 题面来源：https://www.dotcpp.com/oj/1184/ 。题面版权归蓝桥杯大赛组委会所有，此处仅用于学习交流。

## 题目

### 问题描述

在国家精密光学实验室中，研究员正利用两组高功率相干激光器进行 “量子干涉条纹” 锁定实验。

设 1 号激光器的输出功率为 $a$（$0 \le a \le 20269876543210$），2 号激光器的输出功率为 $b$（$0 \le b \le 20260123456789$），其中 $a,b$ 均为非负整数。

物理规律表明，只有当系统总功率 $S=a+b$ 恰好为一个完全平方数时，干涉条纹方可被成功锁定。

请问，一共有多少种不同的功率配给方案 $(a,b)$ 能够使实验成功锁定？由于方案数可能很大，你只需要给出方案数对 998244353 取模后的结果即可。

注意：两个方案 $(a_1,b_1)$ 和 $(a_2,b_2)$ 被认为是不同的，当且仅当 $a_1\ne a_2$ 或 $b_1\ne b_2$。

### 答案提交

这是一道结果填空题，你只需要算出结果后提交即可。本题的结果为一个整数，在提交答案时只填写这个整数，填写多余的内容将无法得分。

## 思路

记 $A=20269876543210$，$B=20260123456789$，$M=998244353$。

1. **枚举平方数而不是枚举 $(a,b)$**：$a+b=S$ 必须是完全平方数。$S$ 的最大值是 $A+B\approx 4.05\times10^{13}$，因此只需枚举 $t$ 使 $S=t^2\le A+B$，即
   $$0\le t\le \left\lfloor\sqrt{A+B}\right\rfloor\approx 6.37\times10^{6}$$
   共约 $6.4\times10^6$ 个平方数，完全可枚举。
2. **固定 $S=t^2$ 后数方案**：要求
   $$a+b=S,\qquad 0\le a\le A,\qquad 0\le b\le B.$$
   由 $b=S-a$，可行区间为
   $$\max(0,\,S-B)\le a\le \min(A,\,S).$$
   若下界不超过上界，则方案数为
   $$\min(A,S)-\max(0,S-B)+1.$$
3. 把每个平方数对应的方案数累加并随时对 $M$ 取模。

**正确性**：任意合法方案 $(a,b)$ 的总和 $S=a+b$ 必是某个平方数 $t^2$，且会被唯一的 $t$ 统计一次；反过来每个被统计的 $a$ 都唯一确定 $b=S-a$ 且满足两个上界，因此计数不重不漏。

## 代码

```java
public class Main {
    static final long MOD = 998244353L;

    public static void main(String[] args) {
        long A = 20269876543210L;
        long B = 20260123456789L;
        long maxS = A + B;

        // 计算 floor(sqrt(maxS))，并修正浮点误差
        long r = (long) Math.sqrt((double) maxS);
        while ((r + 1) <= maxS / (r + 1)) r++;
        while (r > maxS / r) r--;

        long ans = 0;
        for (long t = 0; t <= r; t++) {
            long s = t * t;                       // 总和 S
            long lo = Math.max(0L, s - B);        // a 的下界
            long hi = Math.min(A, s);             // a 的上界
            if (lo <= hi) {
                ans += (hi - lo + 1) % MOD;
                if (ans >= MOD) ans %= MOD;
            }
        }
        System.out.println(ans % MOD);
    }
}
```

## 复杂度

- 时间：$O(\sqrt{A+B})\approx 6.4\times10^6$ 次循环。
- 空间：$O(1)$。

## 易错点

1. $A+B\approx4.05\times10^{13}$ 超出 `int` 范围，所有参与运算的量必须用 `long`。
2. $t^2$ 要用 `long` 计算，若 `t` 声明为 `int`，`t*t` 仍可能溢出。
3. 下界 `s - B` 可能为负，必须与 0 取 `max`；上界 `min(A, s)` 保证 $a\le A$。
4. `Math.sqrt` 的浮点结果可能偏差 1，必须用 `while` 向上、向下修正，不能用除法以外的方式判断。
5. 累加时及时取模；虽然单个区间长度不大，但累加 $6\times10^6$ 项仍可能超过 `long` 安全范围之外的预期值，取模最稳妥。
6. 不要漏掉 $t=0$（对应方案 $(0,0)$）。

## 验证

用上面的程序运行，输出：

```
315082704
```

另外用 Python 的整数平方根 `math.isqrt` 独立实现同一枚举（避免浮点误差），得到的答案同为 **315082704**。

因此本题答案为 **315082704**。
