# 蓝桥杯 Java 大学 B 组备赛

一个可执行的学习闭环：**理解概念 → 识别题型 → 从暴力到满分解法 → 小试牛刀 → AI 打分 → 回填掌握度**。

## 学习闭环

```
docs/05 学会读题与识别题型
        ↓
topics/01~10 概念 + 解法演进 + 模板
        ↓
每章「小试牛刀」限时手写
        ↓
docs/06 用 AI 按 100 分量表打分
        ↓
错题回填 docs/01 考点清单的掌握度
```

## 十类题型

| # | 题型 | 核心收获 | 难度 |
|---|---|---|---|
| 01 | [枚举与模拟](topics/01-枚举与模拟.md) | 把题意翻译成代码，先保证不空题 | 入门 |
| 02 | [排序与贪心](topics/02-排序与贪心.md) | 排序 + 局部最优的证明 | 入门 |
| 03 | [前缀和与差分](topics/03-前缀和与差分.md) | 区间问题从 O(nq) 到 O(n+q) | 基础 |

| 05 | [搜索](topics/05-搜索.md) | DFS/BFS/回溯/剪枝 | 核心 |
| 06 | [动态规划](topics/06-动态规划.md) | 状态定义与转移 | 核心 |
| 07 | [图论](topics/07-图论.md) | 最短路、并查集、拓扑 | 进阶 |
| 08 | [数论](topics/08-数论.md) | 筛法、快速幂、组合数 | 进阶 |
| 09 | [字符串](topics/09-字符串.md) | KMP、哈希、回文 | 进阶 |

每个题型固定包含：**概念 → 如何识别 → 暴力解法（低分）→ 优化 → 满分解法 → 模板 → 小试牛刀（含参考答案）→ 本题型 AI 评分要点**。

## 从哪开始

1. 先读 [如何理解题目与题型](docs/05-如何理解题目与题型.md)，学会看数据范围反推复杂度。
2. 按 [topics/README.md](topics/README.md) 的顺序刷，每章先读概念再看解法演进。
3. 做「小试牛刀」时先自己写，写完用 [AI 评分指南](docs/06-AI评分指南.md) 打分。
4. 分数 < 80 的题型，回到该章重做一遍，并在 [考点清单](docs/01-考点清单.md) 回填掌握度。

## 模板清单

| 模板 | 用途 | 复杂度 |
|---|---|---|
| `FastIO` | 大数据量输入 | - |
| `DSU` | 并查集 | 近似 O(1) |
| `Fenwick` | 单点改 + 前缀和 | O(log n) |
| `SegmentTree` | 区间加 + 区间和 | O(log n) |
| `GraphTemplates` | 建图 / 遍历 / 最短路 / MST / 拓扑 | 见注释 |
| `MathUtil` | gcd / 快速幂 / 素筛 / 组合数 | - |
| `StringUtil` | KMP / 字符串哈希 | - |
| `BinarySearch` | 二分查找 / 二分答案 | O(log n) |

```bash
javac -encoding UTF-8 -d out templates/*.java
```
